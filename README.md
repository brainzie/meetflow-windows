# Meetflow for Windows

The Windows program that connects [Meetflow](https://meetflow.brainzie.co.uk) to a pool's timing console.

## [Download the latest version](https://github.com/brainzie/meetflow-windows/releases/latest/download/Meetflow.exe)

One file, `Meetflow.exe`. Run it on the computer that is cabled to the console: there is nothing to install. Meetflow's **Run the meet** screen links here too.

The first time it runs, Windows may say it doesn't recognise it: choose **More info**, then **Run anyway**. Each release lists the file's SHA-256 fingerprint, so you can check your copy with `Get-FileHash .\Meetflow.exe` in PowerShell.

Which version you have is shown at the top of the program's window, beside its name. [What changed, and the last few versions](https://github.com/brainzie/meetflow-windows/releases/latest).

This repository holds the releases only.
